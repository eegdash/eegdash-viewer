# Benchmark history

This branch stores continuous benchmark results published by
[`benchmark-action/github-action-benchmark`](https://github.com/benchmark-action/github-action-benchmark)
from the **Benchmarks (statistical)** workflow (`.github/workflows/bench.yml`).

Data lives under `dev/bench/`. It is generated automatically on every push to
`main`; do not hand-edit. GitHub Pages for the app itself is deployed from
Actions (`pages.yml`), not from this branch.
